# Интерфейс TreeSize.app на SwiftUI

**Эталон — HTML-отчёт [template.html](../reference/template.html).** Его одобрил CEO. Повторяем его раскладку, цвета, формулировки и поведение средствами SwiftUI. В тексте ниже в скобках даны имена JS-функций эталона. Если что-то неясно — открой функцию и посмотри, как сделано там. Плитки (treemap) не делаем.

Платформа — macOS 14+ (нужны `SectorMark` из Charts и `.onKeyPress`). Только SwiftUI, AppKit, Charts, Foundation. Сторонних пакетов нет.

## 1. Модель (TreeSizeCore, без UI)

`final class Node: Identifiable`:
- поля: `id: Int` (порядковый номер при сборке), `kind: NodeKind` (`.dir`, `.file`, `.rest`), `name`, `size`, `alloc`, `cloud`, `files`, `dirs`, `mtime`, `ign: Int64`, `selfIgnored: Bool`, `weak var parent: Node?`, `var children: [Node]`;
- собирается из массива `serialize()` (см. SPEC.md, формат `node`). Для `ign == -1`: `selfIgnored = true`, `ign = size`;
- имя сводки `.rest` (эталон `aggName`): `"[" + ["N файлов", "M папок"].непустые.joined(" и ") + " помельче]"` с правильным склонением (`plural`). Сводку с `files == 0 && dirs == 0` не показывать нигде;
- путь узла (`pathOf`): у корня — `root`; у остальных — путь родителя + "/" + имя. Для `.rest` вместо имени «…».

`struct ScanResult` — всё остальное из `data`: `root`, `scanned`, `took`, `errors`, `stuck`, `top`, `ext`, `age`, `dups`, `dupMin`, корень `Node`. Конструктор `init(data: [String: Any])`.

## 2. Форматы (Format.swift) — строго как в эталоне

| функция | правило | примеры |
|---|---|---|
| `fmtBytes` (`fmt`) | меньше 1024 → «N Б»; иначе делить на 1024 до КБ/МБ/ГБ/ТБ/ПБ. Число ≥ 100 → 0 знаков, ≥ 10 → 1 знак, иначе 2. Запятая вместо точки | `1536` → «1,50 КБ», `10485760` → «10,0 МБ» |
| `fmtPct` (`pctTxt`) | доля × 100: ≥ 10 → 0 знаков, иначе 1; запятая; « %» | `0.0667` → «6,7 %» |
| `fmtDate` (`dateTxt`) | 0 → «—», иначе `dd.MM.yyyy` в местном поясе | |
| `plural(n, "файл", "файла", "файлов")` | русское склонение; число с разделителем тысяч U+00A0 | «1 234 файла» |

Цвета типов файлов (`GROUPS`) и списки расширений — скопировать из эталона. Имя группы по расширению (`groupOf`), расширение из имени (`extOf`, в TreeSizeCore он уже есть).

## 3. Состояние (AppStore, `@MainActor final class: ObservableObject`)

- `@Published`:
  - `result: ScanResult?`, `selected: Node?`, `menuTarget` (не нужен, если меню строится на месте);
  - `expanded: Set<Int>`, `mode: SizeMode` (`.size` / `.alloc`), `tab: Tab`;
  - `isScanning: Bool`, `progress: (files, bytes, cur)`, `scanPath: String`.
- `value(_ n) -> Int64` — `size` или `alloc` по режиму (`V`).
- `children(_ n)` — дети, отсортированные по `value` по убыванию, без пустых сводок (`kids`).
- `visibleRows: [(node, depth)]` — плоский список раскрытого дерева (`flatten`): корень, затем дети раскрытых папок рекурсивно.
- `select(_ n)` — выделить и раскрыть всех предков (`select`).
- `toggle(_ n)` — раскрыть или свернуть.
- `viewDir` — папка правой панели: выделенная папка или родитель выделенного файла (`dirOf`).
- Режим по умолчанию: для корня, содержащего `/CloudStorage/Dropbox`, — `.size`, иначе `.alloc`. Выбор запоминается в `UserDefaults` отдельно для «dbx» и «disk» (`MODE_KEY`).
- `scan(path)`:
  - скан в фоне (`Task.detached`) через `Scanner` + `scanRoot`;
  - раз в 0,5 с копировать `scanner.nfiles/bytes/cur` в `progress`;
  - по окончании — `result`, выделить корень, раскрыть его;
  - записать `lastRoot` в `UserDefaults`.
- `rescan()` — `scan(result.root)`, после чего выделить узел с тем же путём, что был выделен (или ближайшего сохранившегося предка).

## 4. Окно

Сверху вниз, как в эталоне:

1. **Панель инструментов** (обычный `HStack`, не NSToolbar):
   - логотип из трёх квадратов (синий `#2a78d6` высокий, жёлтый `#eda100` и оранжевый `#eb6834` справа);
   - «TreeSize» жирным и «для мака» серым;
   - путь корня серым с обрезкой посередине;
   - кнопки «📂 Открыть…» (поповер мест, раздел 11) и «⟳ Пересканировать»;
   - сегмент «Размер | На диске».
2. **Плашки** (эталон `#banner`):
   - для Dropbox — фиолетовая с текстом эталона и крестиком. Закрытие запоминается в `UserDefaults`;
   - если `stuck` не пуст — жёлтая «⚠️ N папок прочитать не удалось…» с путями.
3. **Строка сведений о выделенном** (`renderInfo`): имя жирным; «Размер», «На диске», «Доля в родителе» (если не корень), «Только в облаке» (фиолетовым), «Не синхронизируется» и «В квоте Dropbox» (только для Dropbox и если `ign > 0`), «Файлов», «Папок», «Последнее изменение». Подпись серым, значение жирным. Строка переносится.
4. **`HSplitView`**: слева дерево (шире, ~48 %), справа вкладки.
5. **Строка состояния**:
   - путь выделенного (или выбранного в правой панели);
   - кнопки «Показать в Finder» и «Скопировать путь»;
   - справа серым «Скан <scanned> · <took> с · нет доступа: N» (последняя часть — только если `errors > 0`).
6. **Пока идёт скан** — поверх всего затемнение и карточка: «Сканирую <путь>…», ниже «N файлов · X · T с» и текущая папка мелко, обрезанная слева.

Минимальный размер окна 900×560, стартовый 1280×820.

## 5. Дерево (главное, CEO просил отдельно)

Строка (`rowHtml`), высота 26:
- отступ `depth * 16 + 4`;
- стрелка ▸/▾ (только у папок с детьми; клик по стрелке раскрывает);
- иконка:
  - папка — жёлтый `#e9b53b` прямоугольник 16×12 с «ушком»;
  - файл — прямоугольник 11×14 цвета его группы;
  - сводка — пунктирная рамка;
- **полоска**: начинается после иконки, ширина = доля от родителя × (доступная ширина − 62). Скруглённая, градиент слева направо:
  - папки: `#ffd36e` → `#fff0bf`, тонкая рамка `rgba(214,160,20,.35)`; в тёмной теме `#86691c` → `#4a3d17`;
  - файлы: `#c3d6f0` → `#e4ecf7`, в тёмной `#2e4a72` → `#23324a`;
  - сводка — серая;
- поверх полоски — размер жирным (моноширинные цифры, минимум 62 pt) и имя. У корня имя — полный путь;
- у папки с `selfIgnored` — «⊘ не синхр.» серым, имя зачёркнуто;
- если `cloud ≥ size / 2` в режиме «Размер» — фиолетовое «☁»;
- справа колонка процента от родителя, 58 pt, серым;
- выделенная строка — фон `#d6e6fb` (тёмная `#233a5c`) и синяя полоска 2 pt слева.

Поведение:
- клик — выделить;
- **двойной клик по строке — раскрыть или свернуть** (стрелка при этом не мешает);
- клавиши: ↑↓ — соседняя строка; → — раскрыть, а если раскрыта — к первому ребёнку; ← — свернуть, а если свёрнута — к родителю;
- выделенная строка прокручивается в зону видимости.

Реализация: `ScrollViewReader` + `ScrollView` + `LazyVStack` по `visibleRows` с `.id(node.id)`, без `List` и `OutlineGroup`: там не сделать двойной клик и полоску как надо. Двойной клик — `.onTapGesture(count: 2)` перед `.onTapGesture(count: 1)`. Клавиши — `.focusable()` + `.onKeyPress`.

## 6. Вкладка «Диаграмма» (`renderPie`)

- Для `viewDir` взять детей по убыванию.
- Не больше 8 секторов из детей с долей ≥ 1 % и не сводок. Всё остальное — сектор «Прочее» серого цвета (`#b9c1cc`, в тёмной `#5d646f`).
- Цвета по порядку: светлая тема `#2a78d6 #eb6834 #1baf7a #eda100 #e87ba4 #008300 #4a3aa7 #e34948`, тёмная `#3987e5 #d95926 #199e70 #c98500 #d55181 #008300 #9085e9 #e66767`.
- Кольцо: `Chart` + `SectorMark(angle:innerRadius: .ratio(0.6), angularInset: 1)`, слева, ширина ~36 % панели, максимум 380. В центре — сумма крупно и имя папки мелко.
- Справа легенда (строка на сектор):
  - цветной квадрат;
  - имя (папка жирным) и мелко серым «N файлов, M папок» или тип файла, для «Прочее» — «N элементов помельче»;
  - размер жирным; процент серым.
- Наведение на строку легенды подсвечивает строку.
- **Клик по строке легенды или по сектору** (`chartAngleSelection`):
  - папка — `select`;
  - файл — выделить файл;
  - «Прочее» — переключиться на «Детали».
- Сверху — хлебные крошки (`renderCrumbs`): кнопка «↑ Вверх» и путь по сегментам, каждый сегмент кликабелен.

## 7. Вкладка «Детали» (`renderDetails`)

`Table` по детям `viewDir`. Колонки:
- Имя (с иконкой, папки жирным);
- Размер, На диске, Только в облаке (фиолетовым, пусто если 0);
- Файлов, Папок (у файлов пусто);
- % от родителя — серая полоска 90×14 с синей заливкой `#2a78d6` и число;
- Изменено.

Сортировка по клику на заголовок, по умолчанию — по текущему режиму по убыванию. Двойной клик по папке — `select` (`contextMenu(forSelectionType:primaryAction:)`).

## 8. «Расширения», «Возраст файлов», «Топ файлов», «Дубли»

- **Расширения** (`renderExt`):
  - сверху подпись «Типы файлов по всему скану.»;
  - полоса-стопка групп: ширина пропорциональна размеру, промежуток 2 pt;
  - список групп с цветом, размером и процентом;
  - таблица до 300 расширений: «.ext» жирным или «(без расширения)», тип, размер, доля с полоской, файлов, только в облаке.
- **Возраст** (`renderAge`): подпись из эталона; 6 строк: название, полоса (доля от максимума), размер жирным, «X % · N файлов» серым.
- **Топ файлов** (`renderTop`):
  - файлы из `top`, путь которых начинается с пути `viewDir` + "/" (для корня — все);
  - подпись, как в эталоне;
  - таблица: №, имя жирным и «☁» если облачный, под ним папка серым (путь относительно `viewDir`), размер, на диске, изменён.
- **Дубли** (`renderDup`):
  - группы, где хоть один путь внутри `viewDir`;
  - подпись эталона: порог, «кандидаты, а не доказанные дубли», «освободится до X»;
  - каждая группа: «размер × N — лишних Y» и список путей.

## 9. Контекстное меню (`openMenu`) — на строках дерева, деталей, легенды, топа, дублей

Заголовок — имя и размер (у папки ещё число файлов). Пункты:
- «Показать в Finder» → `NSWorkspace.activateFileViewerSelecting`;
- «Скопировать путь» → `NSPasteboard`;
- разделитель;
- только не для корня:
  - для Dropbox — «Не синхронизировать с Dropbox» или «Снова синхронизировать с Dropbox» (если `selfIgnored`). Если исключён предок — неактивная строка «Не синхронизируется: исключена папка «X»»;
  - «Переместить в корзину…».

Для сводок меню нет.

**Корзина** (`doTrash`, `removeLocal`):
1. Подтверждение `NSAlert` с текстом эталона: путь, размер, пояснение про Dropbox. Кнопки «В корзину» и «Отмена».
2. **Сразу** убрать узел из модели: вычесть его `size/alloc/cloud/files/dirs(+1 для папки)/ign` из всех предков, убрать пути из `top` и `dups`. Если выделение было внутри — выделить родителя.
3. В фоне `FileManager.trashItem`, дождаться, пока путь исчезнет (до 3 с).
4. Если ошибка — вернуть узел на место (откатить вычитание) и показать `NSAlert` с ошибкой.

Если пути нет в дереве (свёрнут в сводку), уменьшить сводку ближайшей сохранённой папки на размер из `top`.

**Защита**: `protected()` из эталона — для таких путей пункт корзины неактивен.

**«Не синхронизировать»** (`doIgnore`): подтверждение с текстом эталона → `setxattr("com.apple.fileprovider.ignore#P", "1", XATTR_NOFOLLOW)` → `selfIgnored = true`, `ign = size`, у предков `ign` увеличить. Обратно — `removexattr` обоих имён, `ign` пересчитать как сумму детей.

## 10. Меню приложения

- «Файл»: «Открыть…» ⌘O (открывает поповер мест), «Пересканировать» ⌘R.
- Стандартные «Правка» и «Окно» оставить.

## 11. Поповер «Открыть…» (`renderPlaces`)

- Заголовок «Что просканировать».
- Диски: 💽, имя, «свободно X из Y», полоса занятости (красная, если занято > 90 %).
- Разделитель, затем папки: 📁, имя и путь серым с `~`.
- Текущий корень подсвечен.
- Кнопка «Выбрать папку в Finder…» → `NSOpenPanel` (только папки).
- Поле пути «или путь: ~/Movies, /Volumes/Диск» и кнопка «Сканировать».
- Клик по месту — закрыть поповер и `scan`.

Места — как `places()` эталона: том `/System/Volumes/Data` под именем «Macintosh HD», тома из `/Volumes` кроме ссылки на `/`, домашняя папка, «Загрузки», «Документы», «Рабочий стол», iCloud Drive, всё из `~/Library/CloudStorage`.

## 12. Запуск

Что сканировать:
1. `lastRoot`;
2. иначе `~/Library/CloudStorage/Dropbox`, если есть;
3. иначе домашняя папка.

Аргументы командной строки для проверки: `--root <папка>` (сканировать её, не трогая `lastRoot`), `--snapshot <png>` (раздел 13), `--selftest` (напечатать проверочные факты, раздел 13, и выйти).

## 13. Самопроверка (для исполнителя и приёмки)

- `TreeSizeApp --root /tmp/ts-fixture --selftest` сканирует без окна, строит `AppStore`, выводит JSON с фактами из задачи и выходит с кодом 0.
- `TreeSizeApp --root /tmp/ts-fixture --snapshot /tmp/ts-build/snap.png [--select <путь>] [--tab pie|details|ext|age|top|dups] [--dark]`:
  1. сканирует;
  2. создаёт окно 1280×820 с `NSHostingView(rootView: ContentView)` и выставляет его за экран (`setFrameOrigin(-10000, -10000)`, `orderFront`);
  3. через 1,5 с делает `bitmapImageRepForCachingDisplay` + `cacheDisplay` контента и пишет PNG;
  4. выходит.

  Скриншоты смотрит приёмщик.
