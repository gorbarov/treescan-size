# Задание 12. Финальная косметика

1. **Иконка** (`scripts/make_icon.swift`): логотип из трёх квадратов слишком мелкий — около 22 % ширины. Сделай его примерно 56 % ширины иконки, по центру, те же пропорции (высокий синий слева; справа жёлтый сверху и оранжевый снизу, как на снимке `build/icon_1024.png`, только крупнее). Затем пересобери: `scripts/make_app.sh`.
2. **Поповер «Открыть…»** (`PlacesView.swift`): полоса занятости диска — на всю ширину строки под именем (от иконки до правого края), высота 8, скругление 4. Заливка — доля **занятого** `(total - free) / total` (сейчас около 50 % при занятости 77 %). Красная `#d03b3b`, если занято больше 90 %, иначе `#2a78d6`.
