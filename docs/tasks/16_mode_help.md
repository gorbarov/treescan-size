# Задание 16. Пояснение к переключателю «Размер / На диске»

Пользователи не понимают разницу между «Размер» и «На диске». Нужны подсказки при наведении и кнопка ⓘ с объяснением.

1. **Подсказки при наведении** (`.help(...)`) на половинки переключателя:
   - «Размер» → ключ `"Сколько весят файлы. По нему считают квоту Dropbox и iCloud."`
   - «На диске» → ключ `"Сколько места файлы реально занимают на этом маке."`
2. **Кнопка ⓘ** справа от переключателя: `Button { showModeHelp.toggle() } label: { Image(systemName: "info.circle") }.buttonStyle(.plain).help(tr("Чем отличаются «Размер» и «На диске»?"))` и `.popover(isPresented: $showModeHelp)` с `ModeHelpView`: ширина 360, отступ 16, VStack(alignment: .leading, spacing: 10):
   - заголовок жирным: ключ `"Размер и «На диске» — в чём разница"`
   - абзац: `"**Размер** — сколько весят файлы: столько байт вы получите, если их скопировать. По нему считают квоту Dropbox и iCloud."`
   - абзац: `"**На диске** — сколько места файлы реально занимают на этом маке. Обычно почти то же самое, но есть два исключения:"`
   - строка: `"☁️ Файлы «только в облаке»: размер есть, а на диске — ноль."`
   - строка: `"🧊 Разреженные файлы (например, диск Docker или виртуальной машины): размер может быть 460 ГБ, а занято 39 ГБ."`
   - абзац мелким серым: `"Чтобы освободить место на маке, смотрите «На диске». Чтобы уложиться в тариф облака — «Размер»."`

   Все абзацы — через `mdText(tr(...))` (разметка `**`; хелпер из задания 15).
