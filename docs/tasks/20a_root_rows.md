## 1. Двойной счёт при скане `/` — пути вида `//System`

На скрине CEO корень `/`: «On disk 642 GB» при диске 460 ГБ, внутри `System/Volumes/Data` 321 ГБ **и** рядом `Users` 197 ГБ — том с данными посчитан дважды. Правило `Scanner.shouldSkip` из 18а не сработало: в `listDir` путь собирается как `path + "/" + name`, и для корня `/` получается `//System/Volumes/Data`, а сравнение идёт с `/System/Volumes/Data`. Тест из 18а проверял функцию на «правильной» строке, а не на той, что реально получается при скане.

- Сделай функцию `func joinPath(_ dir: String, _ name: String) -> String` (если `dir.hasSuffix("/")` — без второй косой) и используй её в `listDir` и **везде**, где путь собирается склейкой (`grep -rn '+ "/" +' Sources`).
- `shouldSkip` сделай устойчивым к любому написанию пути: при корне `/` один раз запомни `(st_dev, st_ino)` папки `/System/Volumes/Data` (через `stat`) и пропускай подпапку, у которой `lstat` даёт те же `dev` и `ino`. Сравнение строк оставь запасным вариантом.
- **Проверка на настоящих путях, а не на строке-литерале.** Факт в `--selftest` `root_slash_real_paths`: вызови `listDir("/", timeout: 5)`, найди элемент `System` и проверь, что его путь — ровно `/System`; затем `listDir` этого пути → `Volumes` → `listDir` → `Data`; `Scanner.shouldSkip` для **полученного** элемента `Data` с корнем `/` должен вернуть `true`. Факт — `true`, если всё так.
- Замер (сделай сам, он ~3 минуты, запусти в фоне): `/tmp/ts-build/release/tscan / --json /tmp/root2.json` — итоговое «На диске» (`tree[3]` в JSON) должно быть **меньше 500 ГБ** (занято на диске ~330 ГБ). Впиши цифру в отчёт.

## 5. Стрелки меняют правую часть, а подсветка строки не двигается

`ForEach(rows.indices, id: \.self)` — строки привязаны к номеру позиции, SwiftUI переиспользует строку с тем же номером и может не перерисовать подсветку. Сделай:

```swift
struct TreeRow: Identifiable { let node: Node; let depth: Int; var id: String { node.path } }
// visibleRows возвращает [TreeRow]
ForEach(store.visibleRows) { row in
    TreeRowView(node: row.node, depth: row.depth, isSelected: store.selectedPath == row.node.path)
        .id(row.node.path)
        ...
}
```

`scrollTo` — по `path`. В `moveUp/moveDown` искать индекс по `path`, а не по `id`.
