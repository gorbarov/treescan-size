## 1. Имя — через подстановку `{app}`

- `AppInfo.name = "TreeScan Size"`, `AppInfo.bundleID = "io.github.gorbarov.treescansize"`.
- В `tr(_:)` (`L10n.swift`): результат прогонять через `.replacingOccurrences(of: "{app}", with: AppInfo.name)` — и для русского, и для переводов.
- Во всех `tr("…")` в коде слово `TreeBars` заменить на `{app}`: `grep -rn "TreeBars" Sources`. **Словари `L10n_*.swift` не трогай** — ключи и значения в них с `{app}` поправит Claude отдельным коммитом, сразу после тебя. Пока что `tools/check_l10n.py` будет ругаться на недостающие ключи — это ожидаемо, в отчёте так и напиши.
- `scripts/make_app.sh`: имя бандла с пробелом (`build/TreeScan Size.app`) — все пути в кавычках; исполняемый файл внутри — `TreeScanSize` (без пробела), `CFBundleExecutable` соответственно, `CFBundleName`/`CFBundleDisplayName` = «TreeScan Size». Старый `build/TreeBars.app` удалить скриптом (`rm -rf "build/TreeBars.app"` — это папка сборки проекта, можно).

## 2. Проверка полного доступа — надёжнее

В `Access.hasFullDiskAccess()` проверять **два признака, достаточно любого**:
1. `open("/Library/Application Support/com.apple.TCC/TCC.db", O_RDONLY)` — как сейчас;
2. `opendir(NSHomeDirectory() + "/Library/Safari")` — без полного доступа macOS отвечает «Operation not permitted», **без системного вопроса**; с доступом — открывается.

Больше ничего не открывать для проверки: чтение контейнеров других приложений вызывает системный вопрос.

## 3. Диалог доступа — когда показывать

Флаги в `UserDefaults`: `access.skip` (пользователь выбрал «Продолжить без доступа»), `access.asked` (нажимал «Открыть настройки»).

- Доступ есть → диалог не показывать никогда.
- `access.skip == true` → при запуске не показывать (только по кнопке «Дать доступ» в плашке).
- Нажал «Открыть настройки» → поставить `access.asked = true`.
- Запуск, доступа нет, `access.asked == true` → показать **второй вариант** диалога:
  - заголовок: «Доступ пока не включён для этой копии {app}»;
  - текст: «macOS выдаёт доступ конкретной копии приложения. В списке «Полный доступ к диску» должна быть включена именно эта: <путь к бандлу>. Если в списке другая копия или её нет — перетащите значок ниже в список или нажмите «+».»;
  - путь к бандлу — `Bundle.main.bundlePath`, моноширинным мелким шрифтом, с кнопкой «Показать в Finder» (`NSWorkspace.shared.activateFileViewerSelecting([Bundle.main.bundleURL])`);
  - значок приложения 64 × 64 (`NSApp.applicationIconImage`), который можно перетащить в список настроек: `.onDrag { NSItemProvider(object: Bundle.main.bundleURL as NSURL) }`;
  - кнопки: «Открыть настройки», «Перезапустить {app}», «Продолжить без доступа».
- После перезапуска с доступом — ни одного диалога, сразу работа.

## 4. Стартовый экран вместо пустого окна

Когда нет результата скана и скан не идёт (первый запуск, нет `lastRoot`) — в основной области окна (вместо дерева и вкладок) стартовый экран `WelcomeView`:

- логотип (как в шапке, крупно, 48 pt) и заголовок «Что просканировать?»;
- крупная основная кнопка: «Весь диск — Macintosh HD» и под ней серым «занято 326 ГБ из 460 ГБ» (цифры из `statfs("/System/Volumes/Data")`: занято = `(f_blocks − f_bfree) × f_bsize`, всего = `f_blocks × f_bsize`). Нажатие — скан `/System/Volumes/Data`;
- ниже список мест из `Places` (как в поповере «Открыть…»): домашняя папка, Загрузки, Документы, Рабочий стол, iCloud Drive, Dropbox и прочие облака, внешние диски — строкой: значок, имя, серым путь. Нажатие — скан;
- внизу ссылка-кнопка «Выбрать другую папку…» — тот же `NSOpenPanel`, что у «Открыть…».

`startInitialScan`: если есть `lastRoot` — сканировать его, как сейчас. Если нет — **не** сканировать Dropbox или домашнюю папку автоматически, а показать `WelcomeView`. Флаг `--root` работает как раньше.

Диалог доступа (п. 3) показывается поверх стартового экрана — порядок: сначала доступ, потом выбор, что сканировать.

## 5. Переводы

Все новые строки — через `tr(...)`. Ключи не добавляй в словари: Claude добавит переводы на все языки вместе с `{app}` (п. 1). В отчёте перечисли **все новые русские строки** списком — по нему Claude будет переводить.
