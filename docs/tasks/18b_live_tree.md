# Задание 18б. Живое дерево во время скана

CEO: «лучше бы сканирование шло по верхним папкам, и дерево динамически обновлялось во время сканирования». Сейчас до конца скана (на всём диске — 100 с) пользователь видит только оверлей. Нужно: дерево видно сразу и заполняется по ходу; папки, которые ещё сканируются, помечены; прогресс-бар из 18а остаётся, но не закрывает окно.

## Как устроено (схема — делай ровно так)

`Scanner.scan` рекурсивный: папка попадает в `kids` родителя только когда досканирована целиком, а суммы (`size`, `alloc`, `files`…) у папки растут по ходу. Значит, в любой момент частичное дерево = готовые поддеревья + **стек** папок, которые сейчас сканируются (от корня до текущей).

### 1. Стек в `Scanner` (`Sources/TreeSizeCore/Scanner.swift`)

```swift
private var stack: [Dir] = []          // под lock
public var live: Bool = false          // включать только из приложения; tscan и compare.py не трогает
```

- В начале `scan(...)`, сразу после `let d = Dir(name: name)`: `if live { lock.lock(); stack.append(d); lock.unlock() }`.
- Перед каждым `return` из `scan` (их несколько, проверь все!): `if live { lock.lock(); stack.removeLast(); lock.unlock() }`. Удобнее — `defer` сразу после `append`.
- Когда `live == true`, все изменения полей `d` (`d.kids.append`, `d.size += …`, `d.alloc +=`, `d.files +=`, `d.dirs +=`, `d.cloud +=`, `d.ign +=`, `d.mtime`) делать под тем же `lock`. Когда `live == false` — как сейчас, без блокировок (скорость `tscan` не должна пострадать).

### 2. Снимок частичного дерева

```swift
/// Копия текущего состояния: корень с готовыми детьми + папки в работе (помечены scanning).
public func liveSnapshot() -> Dir? {
    lock.lock(); defer { lock.unlock() }
    guard !stack.isEmpty else { return nil }
    // Идём снизу вверх: копия самой глубокой папки, потом её родитель с этой копией в детях и т. д.
    var child: Dir? = nil
    for d in stack.reversed() {
        let c = d.shallowCopy()            // новый Dir: те же поля-суммы, kids = d.kids (массив копируется)
        c.scanning = true
        if let ch = child {
            c.kids.append(ch)
            c.size += ch.size; c.alloc += ch.alloc; c.cloud += ch.cloud
            c.files += ch.files; c.dirs += ch.dirs + 1
        }
        child = c
    }
    return child                            // это корень
}
```

- Добавь в `Dir` поле `var scanning = false` и метод `shallowCopy()`. Готовые поддеревья в `kids` не копируются вглубь: после завершения они не меняются.
- Суммы у папки из стека не включают ещё не досканированного ребёнка — поэтому в цикле выше его суммы прибавляются к копии родителя. Так цифры у предков растут плавно.

### 3. Сериализация и модель

- `serialize(...)` (Report.swift) должен передать флаг `scanning` в данные узла **только если он `true`**. На готовом дереве флагов нет — формат для `tscan` и `compare.py` не меняется.
- `Node` получает `public var scanning: Bool` (по умолчанию `false`), `Node.build` его читает.
- Для снимка не нужны топ, расширения, возраст, дубли: сделай `ScanResult(liveTree:root:)` — только дерево, остальные списки пустые.

### 4. Приложение (`AppStore.swift`)

- При скане: `scanner.live = true`.
- В цикле прогресса (раз в 0,5 с, уже есть) — раз в **1 с** в фоне: `scanner.liveSnapshot()` → `serialize` с порогом `thr = max(1, Int64(Double(snap.size) * options.minShare))` → `ScanResult(liveTree:)`. Всё это не на главном потоке. На главном только присвоить `store.result = built` и восстановить выделение по `selectedPath` (как после скана в 18а). Раскрытие хранится по путям — не схлопнется.
- При первом снимке раскрыть корень (`expanded.insert(root.path)`), если пользователь ничего не раскрывал.
- Когда скан закончен — как сейчас: полный `ScanResult(data:)`, флагов `scanning` больше нет.
- `isScanning == true` больше **не закрывает** окно оверлеем. Вместо оверлея — полоса над деревом: слева `ProgressView` из 18а (шириной 240), справа текст «123 456 файлов · 41,9 ГБ из 279 ГБ · 1:07» и серым текущий путь в одну строку. Кнопка «Остановить» пока не нужна.
- Вкладки, которым нужен полный скан (Расширения, Возраст, Топ файлов, Дубли), во время скана показывают по центру серым: «Появится после скана».

### 5. Как выглядит папка в работе (`TreeView.swift`)

- Имя папки с `scanning == true` — курсивом, справа от имени `ProgressView().controlSize(.mini)` и серым «сканируется…».
- Размер и полоска показываются как есть (частичные) — они растут.
- Сортировка детей как обычно, по размеру.
