# Правила для исполнителя

Порядок чтения: [docs/SPEC.md](docs/SPEC.md) → [docs/PLAN.md](docs/PLAN.md) → эталон [reference/treesize.py](reference/treesize.py).

1. **Работаешь только внутри `projects/treesize-mac/`.** Эталон `reference/` читать можно, менять нельзя. Если без правки шаблона `template.html` не обойтись — остановись и опиши, что нужно поменять, в `docs/REPORT.md`.
2. **Не удаляй и не отправляй в корзину настоящие файлы.** Действия проверяй только на фикстуре в `/tmp` (`tools/make_fixture.sh`). В Dropbox и домашней папке — только чтение.
3. **Сборочные папки — только `.build/` и `build/`.** Они исключены из синхронизации Dropbox. Новые папки для артефактов не заводи.
4. **Проверку этапа ослаблять нельзя.** `tools/compare.py` и фикстуру не правь, чтобы проверка прошла. Если уверен, что ошибается эталон, опиши случай в отчёте и иди дальше.
5. **Один шаг — один коммит**, сообщение по-русски: `Этап 1.2: сканер`.
6. **Застрял на одной ошибке сборки больше трёх попыток** — запиши её в `docs/REPORT.md` дословно и остановись. Не переписывай подход целиком без согласования.
7. **Сторонние пакеты не подключаются.** Только Foundation, AppKit, WebKit, Darwin.
8. **Комментарии в коде — по-русски**, коротко и только там, где неочевидно, как в эталоне.
