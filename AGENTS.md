# Правила для исполнителя

Порядок чтения: этот файл → [docs/UI-SPEC.md](docs/UI-SPEC.md) (для заданий по интерфейсу) → твоё задание из `docs/tasks/`. Эталоны: сканер [reference/treesize.py](reference/treesize.py), интерфейс [reference/template.html](reference/template.html).

**Как работать с заданием:**
- Делай только своё задание. Следующее не начинай, даже если время осталось.
- Собирать только так: `swift build -c release --scratch-path /tmp/ts-build`. Папка `.build` в проекте не используется.
- Проверка: `tools/check_task.sh NN` (NN — номер задания) должна напечатать `ЗАДАНИЕ NN: OK` или, для заданий по интерфейсу, сделать снимок. Пока не OK — задание не сделано.
- Читать файлы целиком не обязательно: ищи нужное через Grep и читай кусками.
- В конце: коммит `git add -A && git commit -m "Задание NN: …"`. Потом допиши в `docs/REPORT.md` раздел «Задание NN»: что сделал, сколько раз не собиралось и почему, вывод проверки.

1. **Работаешь только внутри `projects/treesize-mac/`.** Эталон `reference/` читать можно, менять нельзя. Если без правки шаблона `template.html` не обойтись — остановись и опиши, что нужно поменять, в `docs/REPORT.md`.
2. **Не удаляй и не отправляй в корзину настоящие файлы.** Действия проверяй только на фикстуре в `/tmp` (`tools/make_fixture.sh`). В Dropbox и домашней папке — только чтение.
3. **Сборка — только в `/tmp/ts-build`, готовое `.app` — в `build/`.** Новые папки для артефактов не заводи. Команды `rm`, `mv`, `xattr`, `osascript`, `open`, `curl` запрещены песочницей. Удалять файлы не нужно: лишнее перезаписывай или оставь и напиши в отчёте.
4. **Проверку ослаблять нельзя.** Ничего в `tools/` не правь: ни `compare.py`, ни `check_task.sh`, ни `expected/`, ни фикстуру. Если уверен, что ошибается эталон, опиши случай в отчёте и иди дальше.
5. **Один шаг — один коммит**, сообщение по-русски: `Этап 1.2: сканер`.
6. **Застрял на одной и той же ошибке больше пяти попыток** — запиши её в `docs/REPORT.md` дословно и остановись. Не переписывай подход целиком без согласования.
7. **Сторонние пакеты не подключаются.** Только Foundation, AppKit, SwiftUI, Charts, Darwin. Версия Swift tools в Package.swift — 5.9, не менять.
8. **Комментарии в коде — по-русски**, коротко и только там, где неочевидно, как в эталоне.
